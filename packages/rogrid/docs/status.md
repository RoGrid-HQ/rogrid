# Status

RoGrid is in early development. This checkout implements typed, generated
events from client to server and server to client. Version `0.2.0` is prepared
locally but has not been published. The CLI generates game-specific code and
loads this runtime as a package; the previously published package is still a
placeholder. The repository playground uses the local source through Rojo so
development does not require publication.

The API may change before a stable release. See [events](events.md) for the
supported declaration syntax, runtime limits, and development workflow.
