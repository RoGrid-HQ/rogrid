# Status

RoGrid is in early development. Package `0.2.0` implements typed, generated
events from client to server and server to client, paired with CLI `0.3.0`.
The CLI generates game-specific code and loads this runtime as a package.
The repository playground uses the local source through Rojo so development
does not require publication.

The API may change before a stable release. See [events](events.md) for the
supported declaration syntax, runtime limits, and development workflow.
